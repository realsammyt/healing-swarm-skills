# Healing Swarm Skills: Agent Instructions

Always-on rules for any coding agent working in this repo (Codex, Devin, Pi, Claude Code, and others).

## Layout

- `.claude/skills/healing-swarm/`: the source library. `manifest.yaml` is the single source of truth for skills, agents, workflows, templates and outputs. `skill-discovery.yaml` holds each skill's description.
- `.claude/skills/healing-swarm/shared/`: safety and style sources (`safety-core.md`, `crisis-response.md`, `contraindications.md`, `ethics-guardrails.md`, and others).
- `.agents/skills/<name>/`: the portable build (open Agent Skills format). Each skill is self-contained, with its files copied into `references/` and the safety core inlined.
- `.claude/skills/<name>/SKILL.md`: the Claude Code discovery copies.
- `website/`: Docusaurus docs site.

## Generated files: don't edit by hand

Everything under `.agents/skills/` and every `SKILL.md` is generated by `scripts/generate-skills.js`. Change the manifest, the discovery file, or the source files under `.claude/skills/healing-swarm/`, then run:

```bash
npm run generate:skills
```

## Before committing

```bash
npm run validate                 # YAML, prompts, ethics, crisis numbers, generated-file freshness
cd website && npm run build      # only if website/ changed
```

YAML strings that contain double quotes must be wrapped in single quotes.

## Safety

Never weaken crisis response, contraindication screening or the ethics "never" rules. Crisis numbers must match `shared/crisis-response.md` (`npm run validate` enforces this).
